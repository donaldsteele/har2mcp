har2mcp▍
Open source · Apache-2.0 · Windows, macOS & Linux

Turn your device's web page into an MCP server.

No official API for your NAS, router or camera? Its admin page calls one. Use the page once, naming each step, and har2mcp writes a Go MCP server so Claude can do the same.

from web page to MCP server
$har2mcp record http://nas.local name each step as you click $har2mcp analyze nas.har --name nas login, session, one tool per action $har2mcp generate nas.spec.yaml ✓ nas-mcp/ go build, then $claude mcp add nas -- ./nas-mcp "List my disks and add a share"
